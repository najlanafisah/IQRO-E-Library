#  IQRA – Online E-Library

**IQRA** is a simple online e-library platform that allows users to borrow books easily. This project was built to support digital literacy through a practical and modern borrowing system.

---

## ✨ Features

-  Search books by title or category
-  Borrow books online with one click
-  User dashboard for borrowing history and status
-  Responsive and clean design (Blade + SCSS)
-  User login and registration

---

## 🛠️ Built With

- **Frontend**: HTML, CSS, JavaScript, SCSS
- **Template Engine**: Blade
- **Backend**: PHP
- **Tools**: Composer, npm

---

## ⚙️ How to Run the Project

> Make sure you have **PHP**, **Composer**, and **Node.js** installed.

### 1. Clone the Repository
```bash
git clone https://github.com/najlanafisah/IQRO-E-Library

cd iqra
```
### 2. Install Dependencies
```bash
composer install

npm install
```
### 3. Setup .env File
> If you're using Laravel:
```bash
cp .env.example .env

php artisan key:generate
```
### 4. Start the App
```bash
php artisan serve

npm run dev
```
### 5. Open in Browser
```bash
http://localhost:8000
```
